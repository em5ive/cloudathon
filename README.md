# UH Cloudathon 2026

## Project Overview
A three-tier serverless AWS architecture designed to modernize
legacy infrastructure and reduce virtualization licensing costs.

## Architecture
- CloudFront + private S3 for frontend delivery
- API Gateway + Lambda for application services
- Aurora PostgreSQL Serverless v2 + RDS Proxy for database operations
- Cognito for authentication
- Amazon Bedrock for AI-assisted customer support
