# Licensing exit assessment

The virtualization price increase and data-center exit are primary drivers. The company has not provided invoices, contracts, license entitlements, core counts or renewal dates. Current licensing expense is therefore **unknown**, not zero. The rows below define the evidence required before finance can approve a savings claim.

| Cost pool | Evidence to collect | AWS comparison and action |
| --- | --- | --- |
| Virtualization platform | Current and quoted renewals, sockets/cores/hosts covered, minimum commitment, support term, termination and notice dates, management/backup add-ons | Compare avoidable annual fees with the total target hosting bill. Record when each host cluster can retire and when the contract can actually be reduced. |
| Operating systems | Windows Server/Linux subscription editions, version, purchased date, Software Assurance/support, physical-core allocation, CAL/RDS access dependencies | For rehosted servers, compare eligible BYOL tenancy plus support with license-included EC2 pricing. Lambda removes these application guest OS installations, but AWS service charges remain. |
| Databases | Oracle/SQL Server editions, options/packs, per-core or server/CAL terms, support, HA/passive rights, cloud mobility eligibility | Rehost with approved license model or replatform where compatible. Aurora PostgreSQL avoids running a commercial DB engine for this POC; extensions, third-party tools and application rewrite costs still need review. |
| Applications and middleware | Vendor/user/core/device entitlements, support, bundled VM rights, SaaS terms, DR and test rights | Obtain written AWS support and licensing confirmation. A move to EC2, containers or Lambda does not automatically cancel vendor licenses. |
| Tooling and support | Monitoring, security agents, backup, hypervisor management, external support contracts | Identify retained tools, replacements and cancellation dates. Do not double-count bundled platform support. |

For each item record owner, contract ID, annual recurring fee, next increase, billing basis, minimum spend, portability, cancellation deadline and evidence location. Finance must distinguish sunk/prepaid amounts from cash that can actually be avoided. Allocate shared costs consistently for workload comparison while keeping an enterprise total that does not count the same host license twice.

**BYOL** uses eligible existing entitlements and may require continued support, dedicated tenancy, license mobility, documented purchase dates or other contract conditions. **License included** embeds applicable vendor license charges in the selected AWS offering and can simplify consumption, but is not license-free. A Windows license and a SQL Server license are separate decisions. Have procurement and the relevant licensing specialist review actual agreements before selecting a model. AWS documents different eligibility and conversion conditions; availability in License Manager is not proof of a customer's rights. See [AWS BYOL considerations](https://docs.aws.amazon.com/prescriptive-guidance/latest/optimize-costs-microsoft-workloads/byol-ded-hosts.html) and [SQL Server licensing options](https://docs.aws.amazon.com/sql-server-ec2/latest/userguide/sql-server-on-ec2-licensing.html).

Evaluate AWS License Manager for discoverable license inventory, self-managed counting rules, compliance alerts, eligible license conversion and cross-account reporting. It can help track continuing obligations during overlap; it does not renegotiate contracts, certify legal compliance or remove charges automatically. Configure it only in an authorized enterprise account, not implicitly in the competition POC. See [License Manager capabilities](https://aws.amazon.com/license-manager/faqs/) and [self-managed rules](https://docs.aws.amazon.com/license-manager/latest/userguide/config-overview.html).

Platform retirement reduces exposure only after applications, retained rollback copies, ancillary appliances and management dependencies no longer require that platform, and the applicable contract can be terminated or resized. Keep a retirement register with workload acceptance, rollback-expiry date, VM deletion approval, host/cluster shutdown evidence, license reassignment rules, cancellation acknowledgment and final invoice. Powered-off VMs or a smaller usage count alone may not reduce a committed contract.

Report savings separately: virtualization fee avoided, guest OS subscription avoided, DB license avoided, application licenses retained, incremental AWS charges, and residual support. Rehosting is useful for the lease deadline even where OS/DB licenses continue. Refactoring this application's web/API tiers to Lambda reduces the number of guest instances and patching tasks; wider application conversion remains a later evidence-based decision.
